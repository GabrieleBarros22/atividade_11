# atividade_11

Atividade 11 - Item Coletável com HUD e Reposicionamento Aleatório

## Descrição

Projeto desenvolvido em Godot 4 para implementar um item coletável em um jogo Top-Down 2D.

Ao encostar no item, o contador da HUD é atualizado e o item reaparece em uma posição aleatória visível na tela.

## Funcionalidades

- Item coletável usando Area2D
- Detecção de colisão com body_entered
- HUD com contador de itens coletados
- Reposicionamento aleatório do item
- Movimentação do player Top-Down
